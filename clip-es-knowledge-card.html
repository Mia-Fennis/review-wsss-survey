CLIP is Also an Efficient Segmenter:
A Text-Driven Approach for Weakly Supervised Semantic Segmentation

首个系统性地将 CLIP 引入 WSSS 的工作，仅需传统方法 10% 的时间生成伪标签
📄 arXiv: 2212.09506 🏫 浙江大学 📅 2022-12 (CVPR 2023) 💻 GitHub 🏷️ CLIP-based 多阶段
作者：Yuqi Lin, Minghao Chen, Wenxiao Wang, Boxi Wu, Ke Li, Binbin Lin, Haifeng Liu, Xiaofei He

01 动机与核心思想

问题

传统 WSSS 多阶段框架训练成本极高，且 CAM 对非目标类和背景的混淆严重。CLIP 展现了强大的零样本定位能力，但如何高效地从 CLIP 生成高质量分割掩码尚未被系统探索。

CLIP-ES 的贡献

CLIP-ES 是 首个系统性地将 CLIP 用于 WSSS 各阶段 的工作，对传统三阶段框架（CAM 生成 → CAM 精炼 → 分割训练）分别做了 CLIP 特化设计：

  • 阶段 1 (CAM 生成)：Softmax GradCAM + 文本驱动策略（锐度提示选择 + 同义词融合）
  • 阶段 2 (CAM 精炼)：基于 CLIP 固有 MHSA 的 CAA 模块，实时生成亲和度，替代 IRN
  • 阶段 3 (分割训练)：置信引导损失 CGL，聚焦高置信区域训练

02 核心方法

2.1 Softmax GradCAM

💡 核心思想

传统 GradCAM 用 ReLU 激活 → 只保留正响应 → 非目标类和背景被错误激活。用 softmax 替代 ReLU 将各 channel 的响应归一化为概率分布，抑制非目标类别。

传统 GradCAM 对类别 c 在像素 (i,j) 的激活值：$M_c^{\text{GradCAM}}(i,j) = \operatorname{ReLU}(\sum_k \alpha_k^c A_k(i,j))$

CLIP-ES 的 softmax GradCAM：$M_c^{\text{S-GradCAM}}(i,j) = \frac{\exp(\sum_k \alpha_k^c A_k(i,j))}{\sum_{c'} \exp(\sum_k \alpha_k^{c'} A_k(i,j))}$

同时利用 CLIP 的零样本能力，先用 CLIP 做零样本分类识别出图像中包含哪些类别，在 softmax 中 排除 不存在的类别 → 显著减少背景混淆。

2.2 文本驱动策略

💡 核心思想

CLIP 的文本输入对 CAM 质量敏感。提出两种策略优化文本 prompt，无需额外训练。

锐度驱动提示选择 (Sharpness-based Prompt Selection)：候选文本模板集 $T = \{t_1, t_2, ..., t_m\}$，对每个模板计算 softmax GradCAM 的锐度（峰值响应），选择锐度最高的模板。

同义词融合 (Synonym Fusion)：每个类别有多个同义词（如 "aeroplane"/"airplane"），分别生成 CAM 后融合。融合策略：对高置信区域取平均，低置信区域取最大值。

2.3 CAA — Class-Aware Attention-based Affinity

💡 核心思想

利用 CLIP-ViT 固有的 MHSA 中的注意力图直接作为像素间亲和度，无需额外训练 IRN。

CLIP-ViT 的 MHSA 输出注意力图 $A \in \mathbb{R}^{H\times W \times H\times W}$，$A(p,q)$ 表示 patch p 对 patch q 的注意力权重。对类别 c，用 softmax GradCAM 图 $M_c$ 选择高置信种子区域，然后通过注意力传播种子到整个物体：

$$\text{Affinity}(p,q) = \frac{1}{N} \sum_{h=1}^N A_h(p,q)$$

其中 N 为注意力头数。CAA 的独特之处在于 类别感知 — 只对当前类别的种子区域进行传播，避免跨类混淆。CAA 运行时间仅 0.2秒/图，而传统 IRN 需 12 秒/图。

2.4 CGL — Confidence-Guided Loss

💡 核心思想

训练分割网络时，对伪标签置信度高的像素赋予高权重，低置信度像素权重低，减少噪声传播。

对像素 i，以其在 softmax GradCAM 中的最大响应值 $w_i = \max_c M_c(i)$ 作为置信度权重：

$$L_{\text{CGL}} = -\frac{1}{N} \sum_i w_i \cdot \log P(\hat{y}_i | x_i)$$

其中 $\hat{y}_i$ 是伪标签，$P(\hat{y}_i | x_i)$ 是分割网络的预测概率。

完整 Pipeline

① Softmax GradCAM
CLIP + 文本驱动 → CAM → ② CAA 精炼
MHSA 亲和度 → 伪标签 → ③ 分割训练
CGL 损失 → DeepLabV2

🎯 噪声实验启示

CLIP-ES 是 CLIP × 多阶段 象限的代表：

  • CAA 是亮点：利用 CLIP 固有注意力图做亲和传播，不引入额外参数，天生比 IRN 更抗噪
  • CGL 直接针对噪声设计：置信度加权训练 → 低置信（高噪声）区域自动降权，噪声实验的天然 baseline
  • Softmax GradCAM 的关键：用 CLIP 的零样本识别排除不存在的类别 → 从源头减少噪声
  • 但微调 CLIP 有风险：不同于 ExCEL 冻结 backbone，CLIP-ES 微调 CLIP → 对抗性噪声可能破坏预训练知识

05 复现要点

⚙️ 关键配置

Backbone：CLIP ViT-B (微调) 或 ResNet101

CAM 生成：Softmax GradCAM + 锐度提示选择 + 同义词融合，完全无需训练

CAA 精炼：基于 CLIP-ViT 的 MHSA 注意力图，0.2s/img

分割网络：DeepLabV2，CGL 损失训练

效率优势：总运行时间约 420 min（VOC），远低于同类

代码：github.com/linyq2117/CLIP-ES

可能踩的坑

  • CLIP 版本敏感：不同 CLIP 变体（ViT-B/16 vs ViT-B/32）的 MHSA 注意力图质量不同，需调优
  • 文本模板选择：锐度驱动提示选择依赖候选模板集的质量，换数据集需重新设计模板
  • 同义词融合的阈值：高/低置信区域的划分阈值需要调参
  • CGL 的权重设计：直接用 softmax 最大值做权重可能在多类重叠区域出现高置信错误
