#01 CVPR 2025 CLIP-based 单阶段

ExCEL: Extremely Efficient Curriculum Learning for WSSS

Sung-Hoon Yoon, Hyeok Ryool Kweon, Kuk-Jin Yoon

arXiv: 2503.20826 · CVPR 2025

问题定义

传统多阶段 WSSS 需要依次训练分类网络 → 亲和网络 → 分割网络，耗时以天计。ExCEL 提出在冻结的 CLIP 视觉编码器上通过课程学习（Curriculum Learning），仅需 90 分钟即可完成单阶段训练，达到接近 SOTA 的 mIoU。

核心洞察
💡 关键发现：直接使用 CLIP 原始 patch-text 匹配得分作为伪标签质量极差（因为 CLIP 训练目标是图像-文本匹配，不是像素级定位）。ExCEL 通过两步改良：文本语义丰富化（TSE）和视觉校准（VC），逐步改进伪标签质量。
架构总览

模块详解
  • TSE — 文本语义丰富化：两个策略：(a) Sharpness-based Prompt Selection — 对每个类别自动选择最合适的 prompt（如 "person with clothes, people, human" 比单独 "person" 更好）；(b) 同义词融合 — 融合多个同义词的 text embedding 以获得更完整的语义覆盖。
  • VC — 视觉校准：通过可学习的 adapter（两层 MLP）对 CLIP 视觉特征进行微调，使得 patch 特征更适配分割任务，减少冻结 CLIP 带来的领域偏移。
  • 课程学习策略：先只用 TSE 训练粗伪标签 → 收敛后加入 VC 校准 → 最终用高质量伪标签监督分割头。每阶段自动推进，无需人工调阈值。

#02 CVPR 2023 CLIP-based 多阶段

CLIP-ES: CLIP is Also an Efficient Segmenter

Yuqi Lin, Minghao Chen, Wenxiao Wang, Boxi Wu, Ke Li, Binbin Lin, Haifeng Liu, Xiaofei He

arXiv: 2212.09506 · CVPR 2023

问题定义

传统 WSSS 三阶段（分类 → 亲和精炼 → 分割训练）训练成本高。CLIP-ES 探索冻结 CLIP 是否能跳过分类网络训练和亲和网络训练两步，直接在 CLIP 上完成高质量的伪标签生成。

核心洞察
💡 关键发现：冻结 CLIP 可以直接用 GradCAM 生成初始 CAM，且仅需 2GB 显存、1 小时内即可完成全部伪标签生成。CAA（跨层注意力亲和）模块利用 CLIP-ViT 自带的 MHSA 替代额外训练的亲和网络，实现训练无关的实时精炼。
架构总览
┌──────────────────────────────────────────────────────────┐ │ CLIP-ES Framework │ ├──────────────────────────────────────────────────────────┤ │ 阶段 1: CAM 生成 (训练无关) │ │ ┌──────────────┐ ┌──────────────────────┐ │ │ │ CLIP ViT-B/16│───▶│ Softmax-GradCAM │ │ │ │ (冻结) │ │ + 类别互斥背景抑制 │ │ │ └──────────────┘ └──────────────────────┘ │ │ │ │ │ ▼ │ │ ┌──────────────────────────────────────┐ │ │ │ CAA (Class-Aware Attention Affinity) │ │ │ │ MHSA 自注意力 → 类感知亲和 → 随机游走 │ │ │ └──────────────────────────────────────┘ │ │ │ │ │ ▼ │ │ ┌──────────────────────────────────────┐ │ │ │ 精炼 CAM → 伪标签 (2GB, <1h 完成) │ │ │ └──────────────────────────────────────┘ │ │ │ │ 阶段 2-3: 分割模型训练 │ │ ┌──────────────────────────────────────┐ │ │ │ DeepLabV2 + CGL (置信度引导损失) │ │ │ │ 忽略不可信像素，专注高置信度区域 │ │ │ └──────────────────────────────────────┘ │ └──────────────────────────────────────────────────────────┘
三阶段详解
  • 阶段 1 — Softmax-GradCAM：在 CLIP 的 GradCAM 中引入 softmax 归一化，使得类别之间变为互斥关系，显著减少类别混淆（如"人"和"牛"同时被激活的问题）。同时定义 25 个类别相关背景词（ground, sky, water...）实现背景抑制。
  • 阶段 2 — CAA (Class-Aware Attention Affinity)：利用 ViT 自带的 MHSA 注意力图，结合 CAM 生成类感知 mask，通过随机游走算法传播高置信度激活到语义相似区域。整个模块无需额外训练，与 CAM 生成在同一前向传播中完成。
  • 阶段 3 — CGL (Confidence-Guided Loss)：训练 DeepLabV2 时，根据 CAM 置信度图动态忽略不可信像素（主要是物体边界区域），仅在高置信度像素上计算损失。VOC 上约 5.4% 的像素被忽略，但 mIoU 提升约 0.5%。

分割网络DeepLabV2 (ResNet101)
分割训练VOC: batch 10, 20k iter
CGL 阈值 μ0.95
硬件TITAN RTX (24GB)

#03 CVPR 2022 CNN-based 多阶段

SIPE: Self-supervised Image-specific Prototype Exploration

Qi Chen, Lingxiao Yang, Jianhuang Lai, Xiaohua Xie

arXiv: 2203.02909 · CVPR 2022

问题定义

传统 CAM 使用全局分类器权重作为"类别中心"来激活每个像素，但不同图像的特征分布差异很大。SIPE 提出为每张图像量身定制图像特定的原型（prototype），而不是使用固定的类中心，从而捕获更完整的物体区域。

核心洞察
💡 关键发现：用 t-SNE 可视化像素级特征分布发现——CAM 的类中心总是给距离近的像素高激活，忽略距离远的像素。而每张图像自己的特征质心（图像特定原型）能激活更完整的物体区域。反过来，改进后的 IS-CAM 通过自监督一致性进一步优化特征表示。
架构总览
┌────────────────────────────────────────────────────────────┐ │ SIPE Framework │ ├────────────────────────────────────────────────────────────┤ │ 阶段 1: 分类网络训练 │ │ ┌──────────────────────────────────────────────────┐ │ │ │ ResNet50 (ImageNet 预训练) │ │ │ │ + 修改骨干: 融合 4 个 stage → 层次化特征 F_h │ │ │ └──────────────────────────────────────────────────┘ │ │ │ │ │ ▼ │ │ ┌──────────────────────────────────────────┐ │ │ │ IPE: 图像特定原型探索 │ │ │ │ ┌──────────────────────────────────┐ │ │ │ │ │ Step 1: 结构感知种子定位 │ │ │ │ │ │ 逐像素计算语义相关性 → 结构图 │ │ │ │ │ │ 与 CAM 计算 IoU → 分配最优类别 │ │ │ │ │ └──────────────────────────────────┘ │ │ │ │ ┌──────────────────────────────────┐ │ │ │ │ │ Step 2: 背景感知原型建模 │ │ │ │ │ │ 用层次化特征 F_h 提取种子质心 │ │ │ │ │ │ 得到 K 个前景原型 + 1 个背景原型 │ │ │ │ │ └──────────────────────────────────┘ │ │ │ │ │ │ │ │ │ ▼ │ │ │ │ IS-CAM = 原型与 F_h 的余弦相似度 │ │ │ └──────────────────────────────────────────┘ │ │ │ │ │ ▼ │ │ GSC 损失: L1 约束 CAM 与 IS-CAM 的一致性 │ │ (自监督信号 → 优化特征表示) │ │ │ │ │ ▼ │ │ ┌──────────────────────────────────────────┐ │ │ │ 阶段 2: 用 IS-CAM 伪标签训练分割网络 │ │ │ └──────────────────────────────────────────┘ │ └────────────────────────────────────────────────────────────┘
模块详解
  • IPE (图像特定原型探索) — 结构感知种子定位：对每个像素 i，计算其与全图所有像素的语义相关性 → 得到该像素的"结构图"。然后将该结构图与 CAM 逐类计算 IoU 相似度，选出最优类别。这一步利用的是像素间关系而非固定的类中心。
  • IPE — 背景感知原型建模：修改 ResNet 骨干网络，融合 4 个 stage 的输出得到层次化特征 F_h（浅层包含颜色/texture 等低层信息，适合建模背景）。在 F_h 空间中提取种子区域的质心作为原型，分别计算 IS-CAM。
  • GSC (General-Specific Consistency)：L1 损失约束原始 CAM（用分类器权重激活）和 IS-CAM（用图像原型激活）的一致性。这个自监督信号使两种 CAM 互相纠错，优化特征表示。

🎯 攻击面：

#04 CVPR 2024 CNN/ViT-based 单阶段

DuPL: Dual Student with Trustworthy Progressive Learning

Yuanchen Wu, Xichen Ye, Kequan Yang, Jide Li, Xiaoqiang Li

arXiv: 2403.11184 · CVPR 2024

问题定义

单阶段 WSSS 面临一个关键问题：确认偏误 (Confirmation Bias)。由于 CAM 伪标签和分割 head 共享骨干特征，错误的伪标签会通过训练不断强化自身、导致退化越来越严重。现有方法简单地用高阈值过滤不可靠像素，但这会丢弃大量可能是正确的像素，导致训练不充分。

核心洞察
💡 关键发现：双学生互相监督可以打断确认偏误的正反馈循环。两个学生网络从不同视角生成多样化的 CAM，互相为对方提供伪标签监督。此外，被过滤掉的不确定区域通过一致性正则化仍然参与训练——"every pixel matters"。
架构总览
┌──────────────────────────────────────────────────────────────┐ │ DuPL Framework │ ├──────────────────────────────────────────────────────────────┤ │ 输入图像 │ │ │ │ │ ┌─────────────┬──────────────────────┐ │ │ ▼ ▼ ▼ │ │ ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │ │ │ Sub-net 1│ │ Sub-net 2│ │ 强增强分支 │ │ │ │ (ViT-B) │ │ (ViT-B) │ │ (一致性正则化) │ │ │ └─────┬────┘ └─────┬────┘ └──────────────────┘ │ │ │ │ │ │ ▼ ▼ │ │ ┌──────────┐ ┌──────────┐ │ │ │ CAM 1 │ │ CAM 2 │ │ │ └─────┬────┘ └─────┬────┘ │ │ │ 差异约束 │ │ │ └──────┬──────┘ ← 互相交叉监督 │ │ ▼ │ │ ┌──────────────────────────────┐ │ │ │ 动态阈值调整 + GMM 自适应滤波 │ │ │ │ 渐进式引入更多可信伪标签 │ │ │ └──────────────────────────────┘ │ │ │ │ │ ▼ │ │ ┌──────────────────────────────┐ │ │ │ 分割头训练 (交叉监督) │ │ │ │ + 不确定区域一致性正则化 │ │ │ └──────────────────────────────┘ │ └──────────────────────────────────────────────────────────────┘
模块详解
  • 双学生网络 (Dual Student)：两个结构相同但参数独立更新的子网络（ViT-B backbone）。通过差异损失（representation-level discrepancy）鼓励两个网络生成多样化的 CAM。交叉监督：Sub-net 1 的伪标签 → 训练 Sub-net 2 的分割头，反之亦然，打断各自的确认偏误。
  • 动态阈值调整 (DTA)：训练初期用高阈值只保留高置信度像素 → 随训练推进逐步降低阈值，引入更多像素参与分割监督。相比固定阈值，能更充分地利用训练数据。
  • GMM 自适应噪声滤波 (ANF)：基于分割损失分布，用高斯混合模型（GMM）自动区分"干净像素"和"噪声像素"。不需要手动设置噪声过滤阈值，自适应调整。
  • 一致性正则化：对被 GMM 过滤掉的不确定区域，施加强增强 → 输入增强后的图像 → 约束分割预测与原始伪标签的一致性。确保即使被过滤的像素也参与训练。

过激活率 (OA) 分析

DuPL 的一个独特贡献是定量分析了确认偏误的严重程度，通过过激活率 (Over-Activation Rate = FP / (TP+FP)) 来衡量。基线方法在很多类别上 OA > 30%，而 DuPL 将 OA 降至 5%-15%。这是噪声测试的重要参考指标。

噪声测试关注点
🎯 攻击面：
① CAM 伪标签注入噪声 → 测试 GMM 自适应滤波的有效性上限（噪声比例 10%~50%）
② 差异损失权重扫描 → 双学生差异度对噪声鲁棒性的影响
③ 动态阈值下降速率 → 过早引入噪声像素 vs 过晚错过训练信号
