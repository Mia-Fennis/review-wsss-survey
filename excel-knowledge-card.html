CVPR 2025

Exploring CLIP's Dense Knowledge for
Weakly Supervised Semantic Segmentation

ExCEL — 通过 patch-text 对齐范式释放 CLIP 的密集知识潜力
📄 arXiv: 2503.20826 🏫 复旦大学 📅 2025-03-26 💻 GitHub 🏷️ CLIP-based 单阶段 高效
作者：Zhiwei Yang, Yucong Meng, Kexue Fu, Feilong Tang, Shuo Wang*, Zhijian Song*

01 动机与核心思想

问题

现有 CLIP-based WSSS 方法（CLIP-ES、WeCLIP 等）主要聚焦于 全局图像-文本对齐（image-text alignment），即利用 CLIP 的图像级分类能力生成 GradCAM。但 CLIP 的 密集知识（dense knowledge），即补丁-文本对齐（patch-text alignment）能力，在 WSSS 中尚未被充分探索。

两个关键挑战

  • 文本语义稀疏性：模板 "a photo of [CLASS]" 只指示物体存在，缺乏定位所需的细节知识
  • 视觉特征细粒度不足：CLIP 的 image-text 配对预训练使其偏向全局表示，q-k 自注意力过度平滑，丢失细粒度空间信息

ExCEL 的解法

提出 patch-text 对齐范式：直接计算文本嵌入与图像 patch token 之间的余弦相似度生成 CAM，取代传统的分类网络 + GAP 流程。对齐的障碍通过两大模块解决：

  • TSE (Text Semantic Enrichment) — 用 LLM 构建知识库，通过隐式属性聚类增强文本语义
  • VC (Visual Calibration) — 包括 SVC（静态，无训练）和 LVC（动态，轻量适配器），校准 CLIP 视觉特征

02 核心方法

2.1 TSE — 文本语义增强

💡 核心思想

用 GPT-4 为每个类生成 n=20 条详细描述 → CLIP 文本编码器编码 → K-means 聚类为隐式属性空间 → 对每个类检索 TOP-K 最相关属性 → 加权聚合到最终文本表示

知识库构建：设计 GPT-4 prompt 格式 "List n descriptions with key properties to describe the [CLASS] in terms of appearance, color, shape, size, or material, etc."，n×C 条描述编码为知识库 $T = \{\Phi(e_i)\}_{i=1}^{n\times C}$。

隐式属性狩猎：K-means 聚类得 B 个质心 $A = \text{Kmeans}(T, B) = \{a_i\}_{i=1}^B$，每个类 c 用全局模板嵌入 $t_c$ 检索 TOP-K 近邻属性：

$$A_c = \{a_j : j \in \operatorname{argtopk}_{j=1}^B t_c^T a_j\}$$

最终文本表示：$T_c = t_c + \lambda \sum_{j=1}^K \operatorname{softmax}(t_c^T a_j) a_j$

2.2 SVC — 静态视觉校准

💡 核心思想

CLIP 的 q-k 自注意力过度平滑→用 Intra-correlation 替换，在中间层各空间 {q,k,v} 内部计算相关性

对第 l 层，SVC 注意力图：

$$S_{\text{attn}}^l = \sum_i w_i \cdot \operatorname{SA}(O_i, O_i), \quad O_i \in \{q, k, v\}$$

其中 l ∈ {12-N, ..., 12}, N=5 为中间层数。每条注意力映射计算三个空间内的自相关性，避免 q-k 的平滑效应。最终从最后一层输出校准特征 $P_s$，与 $T_c$ 通过余弦相似度生成静态 CAM。

$$\text{CAM} = \operatorname{Norm}(\cos(P, T))$$

2.3 LVC — 可学习视觉校准

💡 核心思想

轻量适配器学习动态 token 关系，在 SVC 上叠加分布偏移，不改变 CLIP 预训练权重

动态特征提取：从 CLIP 1-12 层提取冻结特征 $F_l$，通过独立 MLP $\delta(\cdot)$ 和卷积融合：

$$F_d = \operatorname{Conv}(\operatorname{Concat}_{l=1}^{12} [\delta(F_l)])$$

动态关系矩阵：$r = \alpha(\cos(F_d, F_d) - \beta \overline{\cos(F_d, F_d)})$，经 ReLU 激活得 $R$。

优化注意力：$L_{\text{attn}}^l = S_{\text{attn}}^l + \operatorname{softmax}(R)$

多样性损失：利用静态 CAM 的像素亲和度监督动态特征的 token 关系多样性：

$$L_{\text{div}} = \frac{1}{N^+} \sum_{u^+ \in \hat{R}^+} (1-u^+) + \frac{1}{N^-} \sum_{u^- \in \hat{R}^-} u^-$$

总损失：$L_{\text{ExCEL}} = L_{\text{seg}} + \gamma L_{\text{div}}, \gamma=0.1$

2.4 完整 Pipeline

① TSE
LLM 知识库 → 属性聚类 → 文本增强 → ② SVC
Intra-correlation → 静态 CAM → ③ LVC
Adapter → 动态 CAM → ④ 分割训练
动态伪标签 → Decoder

单阶段架构：直接以冻结 CLIP ViT-B 为 backbone，配合轻量 Transformer 分割头 [43]，无需重新训练分类网络。

🎯 噪声实验启示

ExCEL 作为一个 单阶段 + 冻结 CLIP 的方法，对伪标签噪声的鲁棒性可能天然优于需要完整端到端训练的多阶段方法。其 SVC 的 Intra-correlation 避免了 q-k 注意力的平滑效应，LVC 的多样性损失显式抑制 token 同质化——这些机制可能使 ExCEL 在噪声环境下比其他方法更具优势。

需要注意的是：ExCEL 依赖 LLM 生成的属性，这部分引入的外部知识可能在高噪声场景下提供更鲁棒的语义先验，但也可能带来新模态的噪声源（如 LLM 描述不准确）。

07 复现要点

⚙️ 关键配置

Backbone：CLIP ViT-B（冻结，不训练）

优化器：AdamW，lr=1e-4，weight decay=1e-2

训练迭代：VOC 30,000 / COCO 100,000

属性数 B：VOC 112 / COCO 224

SVC 层数 N：5（最后 5 层 Transformer）

缩放因子：α=3.0, β=1.0, γ=0.1

Decoder：简单 Transformer head [43]

LLM：GPT-4，每类 20 条描述

显存需求：3.2 GB（一张 RTX 3090）

训练时间：~90 分钟（VOC）

代码：github.com/zwyang6/ExCEL

可能踩的坑

  • LLM 依赖：需要 GPT-4 API key 来生成类描述（或可用开源 LLM 替代？论文未讨论）
  • K-means 超参数 B：B=112 是在 VOC 20 类上调优的，其他数据集需重新搜索
  • CLIP 版本：论文用 ViT-B，换了其他 CLIP 变体是否需要调参未知
  • Training-free 模式强但有限：SVC 无需训练即可达 74.6%，但 LVC 的训练只提升~3.4%，如果复现时发现 training-free 好但 LVC 加不上，可能是适配器超参问题
