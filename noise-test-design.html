2. 噪声薄弱环节分析

E

ExCEL

🎯 CLIP 视觉编码器

TSE 文本语义丰富 + VC 视觉校准依赖 CLIP 的 patch-text 对齐质量。输入图像噪声会直接传递到对齐得分计算。

📝 Prompt 噪声

文本 prompt 的拼写错误/同义词替换会直接影响语义丰富化分支。

🔧 Adapter 微调

训练时在 adapter 特征中加入 Dropout 噪声，测试小样本适应能力。

D

DuPL

🏷 CAM 伪标签噪声

双学生框架的伪标签自训练中，噪声标签会通过正反馈循环被放大。GMM 滤波是关键防御机制。

⚖️ 双生差异度

改变 discrepancy loss 权重，观察两分支的差异演化对分割质量的影响。

C

CLIP-ES

📉 GradCAM 梯度噪声

Softmax-GradCAM 对类别混淆极其敏感。测试背景类别缺失/错误时 CAM 退化程度。

🕸 MHSA 亲和图噪声

CAA (跨层注意力亲和) 模块依赖 MHSA 输出。注意力 Dropout 会直接破坏亲和图传播。

🎯 CGL 置信度阈值

改变置信度判定阈值，观察像素级伪标签的信噪比变化。

S

SIPE

🌌 特征空间扰动

IPE 的结构种子定位依赖像素级特征相似度。特征空间的 t-SNE 分布偏移会破坏种子定位。

📐 结构相似度噪声

IPE 计算 IoU 时，逐像素相似度累积误差会随阶段加深放大。

🔗 多阶段传播

分别测试每个阶段（种子定位 → 背景原型 → 精炼）的噪声容忍度，评估传播放大效应。
