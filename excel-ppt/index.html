motivation

CLIP 的密集知识被忽略了

❌ 现有做法

CLIP-based WSSS 方法（CLIP-ES、WeCLIP）聚焦 全局图像-文本对齐，利用 CLIP 的图像级分类能力生成 GradCAM。

✅ ExCEL 洞察

CLIP 的 密集知识（dense knowledge），即补丁-文本对齐（patch-text alignment）能力，在 WSSS 中尚未被充分探索。

两个关键挑战

⚠️ 挑战
1 文本语义稀疏性
模板 "a photo of [CLASS]" 只指示物体存在，缺乏定位所需的细节知识
2 视觉特征细粒度不足
CLIP 的 image-text 预训练偏向全局表示，q-k 自注意力过度平滑，丢失细粒度空间信息

method · overview

Patch-Text 对齐范式

直接计算文本嵌入与图像 patch token 之间的余弦相似度生成 CAM，取代传统分类网络 + GAP 流程。

method · 1 / 3

TSE — 文本语义增强

💡 核心思想

用 LLM 生成详细描述 → 聚类为隐式属性空间 → 检索最相关属性 → 加权聚合到最终文本表示

📝 GPT-4 prompt: "List n descriptions with key properties to describe the [CLASS] in terms of appearance, color, shape, size, or material, etc."
🧮 n=20 条描述/类 × C 类 = n×C 条 → CLIP 编码 → 知识库 T = {Φ(eᵢ)}
🔬 K-means 聚类得 B=112 个质心 → 每类检索 TOP-K 近邻属性
TSE 公式
// 隐式属性狩猎
A = Kmeans(T, B) = {aᵢ}ᵢ₌₁ᴮ

// 每类检索 TOP-K
A_c = {aⱼ : j ∈ argtopkⱼ₌₁ᴮ t_cᵀ aⱼ}

// 加权聚合
T_c = t_c + λ Σ softmax(t_cᵀ aⱼ) aⱼ

// 最终 CAM
CAM = Norm(cos(P, T))

method · 2 / 3

SVC — 静态视觉校准

💡 核心思想

CLIP 的 q-k 自注意力过度平滑 → 用 Intra-correlation 替换，在中间层各空间 {q, k, v} 内部计算相关性

📐 对每层 l，SVC 注意力图：
Sl_attn = Σ wᵢ · SA(Oᵢ, Oᵢ), Oᵢ ∈ {q, k, v}
🔢 l ∈ {12-N, ..., 12}, N=5 为中间层数
✅ Training-free：无需训练，直接替代 q-k attention

method · 3 / 3

LVC — 可学习视觉校准

💡 核心思想

轻量适配器学习动态 token 关系，在 SVC 上叠加分布偏移，不改变 CLIP 预训练权重

⚙️ 从 CLIP 1-12 层提取冻结特征 Fl → 独立 MLP δ(·) → 卷积融合
🔗 动态关系矩阵 r = α(cos(Fd,Fd) - β·mean) → ReLU → R
🎯 多样性损失 Ldiv 显式抑制 token 同质化

总损失：L = Lseg + γLdiv, γ=0.1

注意力特征演变

❌ CLIP q-k → 过度平滑（mIoU 11.2%）

🎯 噪声实验启示

单阶段+冻结 CLIP 的方法对伪标签噪声鲁棒性可能天然优于多阶段端到端训练。SVC 的 Intra-correlation 和 LVC 的多样性损失显式抑制 token 同质化。

⚠️ 需注意

ExCEL 依赖 LLM 生成属性——外部知识在高噪声场景提供更鲁棒语义先验，但也可能引入新模态噪声（LLM 描述不准确）。

reproduction

复现要点 & 可能踩的坑

config.json
backbone: CLIP ViT-B # 冻结
optimizer: AdamW
lr: 1e-4 / weight decay: 1e-2
iters: VOC 30k / COCO 100k
attributes B: VOC 112 / COCO 224
SVC layers N: 5 # 最后 5 层
scaling: α=3.0 β=1.0 γ=0.1
decoder: 简单 Transformer head
LLM: GPT-4 × 20 desc/class
GPU: 1× RTX 3090 (3.2 GB)
⚠️ 1

LLM 依赖

需要 GPT-4 API key。论文未讨论开源 LLM 替代方案。

⚠️ 2

B 值搜索

B=112 是在 VOC 20 类上调优的，其他数据集需重新搜索。

⚠️ 3

CLIP 版本

论文只用 ViT-B，换了其他变体是否需要调参未知。

⚠️ 4

Training-free 陷阱

SVC 无需训练达 74.6%，但 LVC 只提升 ~3.4%。如果 LVC 加不上，可能是适配器超参问题。
