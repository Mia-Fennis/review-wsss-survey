DuPL: Dual Student with Trustworthy Progressive Learning
for Robust Weakly Supervised Semantic Segmentation

双学生互相监督 + 渐进式学习 + 自适应噪声过滤，专为对抗 CAM 确认偏误设计
📄 arXiv: 2403.11184 🏫 上海大学 📅 2024-03-17 💻 GitHub 🏷️ 非 CLIP 单阶段
作者：Yuanchen Wu, Xichen Ye, Kequan Yang, Jide Li, Xiaoqiang Li

01 动机与核心思想

问题：CAM 确认偏误 (Confirmation Bias)

单阶段 WSSS 中，分类网络生成的 CAM 伪标签直接用于训练分割头。由于 backbone 特征共享，不准确的 CAM 不仅妨碍分割学习，更会反过来强化 CAM 的错误判断，形成恶性循环。这种确认偏误随训练持续恶化。

💡 核心洞察

传统方法用固定高阈值过滤不可靠伪标签 → 丢弃了大量可能正确的像素。DuPL 提出：每个像素都重要，即使不可靠的区域也应通过一致性正则化得到利用。

三大组件

  • Dual Student 框架 — 双子网互相监督，从不同视角产生多样化 CAM，缓解确认偏误
  • Trustworthy Progressive Learning — 动态阈值调整（余弦下降）+ 自适应噪声过滤（GMM），逐步引入更多像素
  • Every Pixel Matters — 对过滤掉的区域做一致性正则化，不浪费任何像素

02 核心方法

2.1 Dual Student 框架

💡 核心思想

两个相同架构的子网（ψ₁, ψ₂），参数独立不共享。表示层差异损失 $L_{\text{dis}}$ 强制二者特征多样化。子网 1 的 CAM 伪标签监督子网 2 的分割训练，反之亦然 → 交叉监督打破确认偏误。

差异损失：$D(f_1, f_2) = -\log(1 - \frac{f_1 \cdot f_2}{\|f_1\| \times \|f_2\|})$, $L_{\text{dis}} = D(f_1, \Delta(f_2)) + D(f_2, \Delta(f_1))$

分割损失（交叉监督）：$L_{\text{seg}} = \text{CE}(P_1, Y_2) + \text{CE}(P_2, Y_1)$

2.2 Trustworthy Progressive Learning

动态阈值调整 (DTA)：背景阈值 $\tau_h$ 随训练余弦下降：$\tau_h(t) = \tau_h(0) - (\tau_h(0) - \tau_h(T)) \cdot \frac{1}{2}(1 - \cos(\frac{t\pi}{T}))$

2.3 自适应噪声过滤 (ANF)

💡 核心思想

基于「深度网络先拟合 clean labels 后记忆 noisy labels」的早停现象。用 GMM 拟合分割损失分布，高损失组分自动识别为噪声。

损失分布建模：$P(l^x) = w_c \mathcal{N}(l^x|\mu_c, \sigma_c^2) + w_n \mathcal{N}(l^x|\mu_n, \sigma_n^2)$

2.4 Every Pixel Matters

对被 ANF 过滤的不可靠区域，用强数据增强 $\phi$ 扰动后做一致性正则化。

完整目标

$L = L_{\text{cls}} + 0.1 L_{\text{dis}} + 0.1 L_{\text{seg}} + 0.05 L_{\text{reg}}$

04 噪声实验视角

🎯 四篇总结：2×2 矩阵
  • ExCEL (CLIP×单阶段): 冻结 backbone 被动抗噪，最高性能 (78.4) + 最高效率 (90min)
  • CLIP-ES (CLIP×多阶段): CAA+CGL 抗噪设计，零样本 70.8% CAM，效率第二
  • DuPL (非CLIP×单阶段): 四篇中唯一主动建模噪声的方法 — ANF 用 GMM 检测噪声像素
  • SIPE (非CLIP×多阶段): 最传统，无专门抗噪设计，但对理解 CAM 与原型的关系有价值

DuPL 的 ANF 模块对噪声实验最具直接参考价值：GMM 损失分布建模 → 区分 clean/noisy → 可在噪声实验中作为检测伪标签噪声的 tool。

05 复现要点

⚙️ 关键配置

Backbone：ViT-B，双子网独立参数 | 优化器：AdamW, lr=6e-5
